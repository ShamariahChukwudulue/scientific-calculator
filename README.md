# Scientific Calculator

A responsive scientific calculator built with **HTML, CSS, and JavaScript**. The project provides both basic arithmetic operations and a range of scientific functions through an interactive browser-based interface.

## Features

* Basic arithmetic operations

  * Addition
  * Subtraction
  * Multiplication
  * Division
* Percentage calculations
* Square and square root operations
* Powers and exponents
* Factorial calculations
* Trigonometric functions

  * Sine
  * Cosine
  * Tangent
* Inverse trigonometric functions
* Natural logarithm
* Base-10 logarithm
* Mathematical constants such as π and e
* Delete and clear functions
* Previous-answer functionality
* Interactive calculator buttons
* Responsive interface

## Technologies Used

* **HTML5** — Page structure
* **CSS3** — Styling and responsive layout
* **JavaScript** — Calculator logic and user interaction

## How to Run

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder.

3. Open `index.html` in a web browser.

No backend or database is required.

## How It Works

The calculator uses JavaScript to capture button interactions, construct mathematical expressions, process scientific functions, and update the calculator display dynamically.

For example, mathematical expressions entered through the interface are processed by JavaScript before the result is displayed to the user.
